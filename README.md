This is a mini project designed for anyone that reads books, in which they can add their books, view them, mark them as read, and save them! It's an easy and simple way to keep track of all the books that you have read and adding more of them when more come your way! I built this project by learning python over the summer before my freshman year of college, because I am a highly interested and curious individual when it comes to reading books, and thought that I should just create a project that would help me keep track of all the literature I read. The way it works is highly simple. The program will first ask you to choose one of four options: Either one, you add a book, two, you view all books, three, you mark a book as read, or four, you quit. The books get saved automatically, so the next time you open the program everything stays where it was when you left it. In order to run the project, you have to clone the repository, have Python installed, and run python3 main.py in your terminal or python main.py depending on what system you have.
